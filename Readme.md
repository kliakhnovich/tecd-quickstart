# T-ECD: quickstart

**T-ECD** (T-Tech E-commerce Cross-Domain Dataset) — открытый анонимизированный
датасет пользовательских взаимодействий из реального e-commerce.

Он подходит для учебных и исследовательских задач по рекомендательным системам:
лабораторных, курсовых, дипломов и научных экспериментов.

T-ECD сохраняет свойства промышленных e-commerce данных: временную структуру,
разреженность, popularity bias, разные типы действий, разные поверхности взаимодействия
и несколько доменов с пересекающимися пользователями.

- Датасет: https://huggingface.co/datasets/t-tech/T-ECD
- Статья на Habr: https://habr.com/ru/companies/tbank/articles/950696/
- Научная публикация: https://doi.org/10.1145/3770855.3817588
- Быстрый старт: [`T-ECD_quickstart.ipynb`](T-ECD_quickstart.ipynb)
- Идеи задач: [`usecases.md`](usecases.md)

---

## Что внутри

T-ECD содержит:

- события пользователей: `view`, `click`, `clickout`, `like`;
- временные метки событий;
- несколько e-commerce доменов, например `marketplace`, `retail`, `offers`, `reviews`, `payments`;
- поверхности взаимодействия через `subdomain`: каталог, поиск, рекомендательные блоки;
- каталог товаров: категории, подкатегории, бренды, контентные эмбеддинги;
- анонимные признаки пользователей: регион и соцдем-кластер;
- две версии датасета:
  - `small` — для учебных задач и быстрых экспериментов;
  - `full` — для проверки методов на промышленном масштабе.

## Быстрый старт

Готовый сквозной пример есть в ноутбуке:

[`T-ECD_quickstart.ipynb`](T-ECD_quickstart.ipynb)

Ноутбук рассчитан на обычный ноутбук или бесплатный Google Colab.  
Он содержит установку зависимостей, сам скачивает небольшой срез данных с Hugging Face
и показывает полный минимальный пайплайн работы с T-ECD.

Что делает ноутбук:

1. загружает небольшой срез T-ECD;
2. показывает структуру таблиц;
3. строит train/validation/test-разбиение по времени;
4. обучает бейзлайны `Random` и `TopPopular`;
5. обучает модель `iALS`;
6. считает `HitRate@k`, `NDCG@k`, `Coverage@k`;
7. показывает рекомендации вместе с категориями товаров.

Если хотите выбрать другой домен, период или объём данных, измените параметры
в начале ноутбука.

## Требования к ресурсам

| Сценарий | Ресурсы |
|---|---|
| `small`, один домен, окно 1–4 недели | ноутбук или Google Colab, 8–16 ГБ RAM, GPU не нужен |
| `small` целиком или нейросетевые модели | 16+ ГБ RAM, GPU желателен |
| `full` | распределённое обучение, ориентир — многокарточная конфигурация, например 8×H100 |

Если ресурсов мало, можно уменьшить объём данных:

- взять один домен;
- ограничить диапазон дней;
- оставить top-N активных пользователей;
- оставить top-N популярных товаров;
- читать только нужные колонки из parquet-файлов.

## Важное про оценку

Для рекомендательных систем не стоит делать случайный train/test split:
так в обучение могут попасть события из будущего.

Базовый корректный протокол:

```text
train      — прошлое
validation — ближайшее будущее для подбора параметров
test       — следующий период для финальной оценки
```

Такое разбиение реализовано в [`T-ECD_quickstart.ipynb`](T-ECD_quickstart.ipynb).

## Примеры задач

T-ECD можно использовать для:

- анализа поведения пользователей в e-commerce;
- построения и оценки рекомендательных систем;
- сравнения бейзлайнов и персонализированных моделей;
- изучения popularity bias и diversity;
- cold-start рекомендаций;
- cross-domain recommendation;
- sequential recommendation;
- исследования влияния поиска, каталога и рекомендательных блоков на поведение пользователей.

Больше идей для лабораторных, курсовых, дипломов и исследований:
[`usecases.md`](usecases.md)
